DanMachi Battle Chronicle (offline edition) - English Patch
============================================================

What it does (the translation-only version includes just the first two points)
- Translates the game's text into English: story, menus, skills, items, missions.
- Translates the Japanese drawn into images: tutorials, gacha banners, honor plates,
  loading tips, battle banners.
- Fairer gacha: each pull gives 5 exchange tokens (50 tokens buy any character in the
  exchange shop, so every ten-pull earns a character of your choice); top-rarity rate 2.5% -> 7.5%.
- More crystals from the story: first clears pay 150 / 300 / 500 crystals (normal / hard / very hard).
- Less grind: double EXP, gold and upgrade-material drops from quests.
- Smarter auto-battle: healing skills and assists only fire when someone is below 70% HP.
- Higher detail: models keep full detail further from the camera.

Requirements
- The final offline edition of the game (PC build, October 2025). The installer checks this.

Install
1. Put this whole DanChro-English-Patch folder inside the game folder (next to danchro.exe).
2. Close the game.
3. Windows: double-click install-windows.bat
   macOS:   double-click install-mac.command (right-click > Open the first time)
4. Choose a version:
   1 = Full patch (English + every change listed above)
   2 = Translation only (English text and images; gameplay exactly as shipped)
The original files are backed up to the "backup" folder inside this folder. You can run the
installer again at any time to switch versions.

If the Windows installer says a file could not be copied, the game folder's path is probably
too long for Windows. Move the game to a shorter path (for example C:\Games\DanChro) and run it again.

Uninstall
Run uninstall-windows.bat or uninstall-mac.command. Your save data is never touched.
